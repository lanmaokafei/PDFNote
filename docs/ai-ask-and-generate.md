# AI 问答与出题（0.61.0）

在脑图里右键任意有内容的卡片：

- **AI 解析这张卡**：结果写入笔记，重复点击会**整段替换**旧结果，不再叠加多份「【AI 解析】」。
- **AI 问答…**：围绕这张卡提问，答案只在面板里显示，**不写回笔记**。
- **AI 出题…**：让模型出 4 道问答草稿，勾选后建成当前卡的子节点。

## 数据流

| 动作 | 命令 | 副作用 |
| --- | --- | --- |
| AI 解析 | `explain_card` | 写回 `user_note`（替换旧解析段） |
| AI 问答 | `ask_card` | 无，只返回文本 |
| AI 出题 | `generate_card_questions` | 无，返回草稿；建卡由前端完成 |

三个命令共用同一套模型配置、超时与 504 任务轮询（`ai::complete_text`），未配置模型时统一报「尚未配置模型」。

## 提示词约定

- 问答：只依据卡片内容回答，卡片里没有就直说「卡片里没有提到」，不编造。
- 出题：只输出 JSON 数组 `[{"question": "...", "answer": "..."}]`；解析时容忍 ```json 围栏与前后寒暄，
  缺字段的条目直接跳过（宁可少几道，也不塞半截内容）。
- 出题数量 1–8（默认 4，UI 未暴露数量选择）。

## 去重实现

`aiNote.ts` 的 `stripAiAnalysis` 以 `【AI 解析】` 为界：标记前是用户自己的笔记，标记后整段视为旧解析丢弃；
`mergeAiAnalysis` 再用新结果拼回去。所以连点 5 次也只有一段解析。

## 边界

- 出题结果**依赖模型是否听话**：不返回 JSON 或字段缺失时会提示“没有返回可用题目”，不会兜底编题。
- 出题生成的卡片是当前卡的子节点，没有 PDF 页码（`source_ref` 为空），不会出现在原文回跳里。
- 问答历史只在面板内存里，关闭即清空，不写库。
- 未配置模型时三个入口都会失败，不会静默降级成本地规则。
