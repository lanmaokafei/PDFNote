# AI 拆书：把厚书变成可学的结构（0.15.0）

目标：一键把论文 / 教材拆成「问题驱动」的脑图骨架，每个节点带原文摘录与页码，可回跳来源。
超过 100 页也能跑：**先笔记、后整理**，分块处理且可中断续跑。

## 两种阶段

| 阶段 | 做什么 | 存在哪里 |
| --- | --- | --- |
| ① 先笔记 | 每 8 页（可调 2–30）一块，抽取摘要 + 条目（标题 / 摘录 / 页码 / 别名） | `book_analysis`，按 (文档, 模式, 块号) 唯一，重跑只补未完成的块 |
| ② 后整理 | 把所有块的笔记汇总成层级骨架（限 80 节点、4 层） | `book_outline` |
| ③ 写入 | 骨架落成卡片 + 脑图坐标，节点通过 `page + bbox` 链回原文 | `cards` / `mindmap_layout` |

写入时**不创建 annotation**：节点在 PDF 上不会画整页高亮，但卡片保留来源页与位置，可从卡片回跳。
重复点「写入脑图」按「同文档 + 同标题」去重，不会翻倍。

## 四种姿态

| 模式 | 抽什么 | 适合 |
| --- | --- | --- |
| 结构 | 背景 / 方法 / 结果 / 讨论，或章节要点 | 论文、教材通读 |
| 智能词典 | 术语 + 定义 + 别名（`aliases` 写进 `cards.link_aliases`） | 与标题链接联动，术语自动成为关键词 |
| 英文生词 | 单词 / 短语，按 CEFR（A2–C2）分级，附原句与释义 | 英文教材、paper 精读 |
| 题目 | 把内容转成可自测的问题，答案取原文 | 应试、复习前自检 |

## 入口

- 文档工作台顶部「AI 拆书」（非嵌入布局）；
- 底部工具坞 →「更多」→ 菜单顶部「AI 拆书」（嵌入布局也能用）；
- 向导内可切模式、选页码范围（全书 / 当前页附近 / 手动），随时「清空重来」。

## 文本从哪来

- **有文字层的 PDF**：pdf.js `getTextContent()`，顺带算出每页文字区域的归一化包围盒；
- **扫描页**：回退到 Apple Vision 的行级 OCR 缓存（`page_ocr`），没有缓存就跳过该页并计入进度。

所以「Vision 负责看扫描页、LLM 负责结构化」，与既有 OCR 管线一致；未引入 Core ML 本地模型，
文本模型仍走「设置」里配置的 OpenAI 兼容通道（本机 Ollama / LM Studio 或云端）。

## 数据模型（schema v8）

```sql
book_analysis(document_id, mode, chunk_index, page_start, page_end,
              summary, items_json, pages_json, created_at, updated_at)
book_outline(document_id, mode, outline_json, updated_at)
```

两表都以 `document_id` 外键级联删除；整库备份/恢复与合并导入都会带上（合并时按内容哈希重指向本地文档）。

## 稳健性

- 模型输出容忍代码围栏与前后解释：从第一个 `{` 到最后一个 `}` 兜底解析。
- 页码会校验在分块范围内，越界引用降级为 `null`；标题截断 80 字、摘录 600 字。
- 单块上限 24 000 字；汇总提示词截断 20 000 字，避免上下文爆掉。
- 汇总结果限 80 节点、4 层，防止模型输出失控。
- 某一块失败不会丢掉已完成块：重新点「继续分析」只会补未完成的块。

## 限制

- 拆书质量取决于模型与文字层质量；扫描页依赖 OCR 缓存，倾斜 / 竖排页可能抽错。
- 节点原句可能被模型轻微改写（提示词要求照抄），重要结论需回原文核对。
- 不做「AI 浮球」常驻面板；入口在文档内，模式切换在向导里。
- 生成的是独立卡片（`surface_pdf = 0`），不会自动进入 PDF 侧栏标注列表。

## 验证

```bash
npm run dev -- --host 127.0.0.1
STEP=digest CARD_COUNT=12 node scripts/mindmap-regression.mjs
```

冒烟覆盖：打开向导 → 分块分析（调用 `analyze_book_chunk`）→ 汇总（`synthesize_book`）→
写入（`apply_book_outline`），并断言分块笔记确实落库。

Rust 侧另有 4 项测试：JSON 容错解析、页码越界丢弃、骨架写入卡片与布局（含重复应用去重、
不生成 annotation）、层级深度与节点数上限。
