# 复习 AI 提示（0.62.0）

复习页正面（未揭示）新增 **AI 提示**：让模型给一条不剧透的线索，帮你回忆，而不是直接给答案。

## 交互

- 点 **AI 提示** → 请求 `hint_card`，面板显示一句到两句提示；
- 已经给过提示时按钮变成 **换个提示**，可再要一条；
- 揭示答案后提示面板自动隐藏，评分区只显示对比结果与四档按钮；
- 换卡时提示清空（只存在当前会话内存，不写数据库）。

## 提示词

模型能同时看到问题与参考答案，但系统提示明确要求：

- 只输出一到两句中文；
- **不给最终答案、不复述原文结论、不列完整要点**；
- 用提问、范围限定、结构线索或联想方向引导（例：「想想它在信息论里的位置」）。

因此提示里出现的是方向，不是结论。答案只用于让模型判断「什么不能说」。

## 边界

- 提示**不参与 FSRS**：不会因为用了提示而降低下次间隔，也不记录「用了几次提示」；需要严格控制时请自行在评分时降档。
- 提示不写回卡片笔记，也不进复习历史；关闭/刷新即消失。
- 未配置模型时按钮会报「尚未配置模型」，不会退化成规则提示。
- 只在闪卡复习页提供；PDF 文档回忆与脑图回忆暂无提示入口。

## 验证

```bash
node scripts/review-answer-smoke.mjs
```

断言：点提示后出现面板、文本含预期线索、**不出现答案区**、卡片正文不含原文答案、
面板含「影响评分」说明。Rust 单测 `hint_prompt_keeps_answer_out_of_the_instruction`
检查提示词包含「不剧透 / 不给最终答案」且空卡片会报错。
