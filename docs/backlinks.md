# 反向链接（0.59.0）

`card_links` 是单向的（source → target）；反向链接不是新数据，而是**同一张表的反向索引**。

## 在哪看

- **节点角标**：脑图里凡是「被别的卡引用」的节点，标题右侧会出现 `←N`；点击直接打开面板。
- **右键菜单 → 反向链接…**：面板里分两段：
  - **被引用**：哪些卡指向当前卡（谁引用我）；
  - **引用出去**：当前卡指向哪些卡（我引用谁）。
- 每行都能「打开」（跳到那张卡：脑图选中并居中）或「取消链接」（直接删这条链接）。
- 没有链接时给空态提示，不显示空白列表。

## 实现

- `src/features/card/backlinks.ts`：`buildLinkIndex` 一次遍历建 `bySource` / `byTarget` / `inboundCounts`，
  节点只做 O(1) 查表；1,000 张卡也不会在渲染里反复过滤。
- 角标数只算**入链**；超过 99 显示 `99+`。
- 面板通过 `listCardLinks()` 自己读链接，删除后写回内存并广播 `pdfnote:links-changed`，
  脑图连线与角标同步更新。
- 角标点击用 `pdfnote:open-backlinks` 事件派发，避免给每个节点传回调、破坏 React Flow 的引用稳定性。

## 边界

- 链接是单向语义：A 引用 B 不代表 B 引用 A；面板把两个方向分开展示，不做“双向合并”。
- 只显示链接关系，不显示链接建立时间与标签（`label` 字段暂未在 UI 使用）。
- 卡片删除后链接随之级联删除；回收站里的卡片不在角标统计里（它们已从查询结果排除）。
- 反向链接面板不做跨画布聚合：角标只统计当前载入的链接（全库链接表，但卡片是否可见取决于当前画布）。

## 验证

```bash
STYLE_LINK=1 STEP=backlinks CARD_COUNT=3 node scripts/mindmap-regression.mjs
```

断言：只出现 1 个角标且数字为 1 → 面板被引用 1 / 引用出去 0、来源是「概念卡片 1」→
点「打开」后选中 1 个节点且面板关闭 → 取消链接后计数归 0、链接表清空、角标消失。
单测 `backlinks.test.ts` 4 项：入/出链分离、角标只算入链、无链接返回空数组、角标文字上限。
