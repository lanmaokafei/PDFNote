# 卡片盒看板（0.34.0）

> 目标：把散落在各本书、各张脑图里的卡片汇到一个可视化看板，按标签 / 书目 / 复习状态分栏，
> 支持多级分组、过滤与拖动改标签。**不改数据库结构**，数据全部来自现有的 `list_cards`、
> `list_tags` 与 `list_documents`。

## 入口与布局

顶栏「卡片盒」（`LayoutGrid` 图标）→ 全宽看板：

- 顶部：卡片总数 / 已打标签 / 未分组 / 待复习四个计数。
- 工具行：搜索框、一级分组（标签 / 书目 / 状态）、二级分组（不分 / 标签 / 书目）、
  书目过滤、标签过滤、状态过滤、「只看待复习」、重新载入。
- 主体：横向滚动的分栏，每栏可独立纵向滚动。

## 分组规则

| 一级分组 | 列 | 说明 |
|---|---|---|
| 标签 | 每个标签一列 + 末位「未分组」 | 多标签卡片会**同时出现在多列**（这是标签看板的正常语义，计数按落位算） |
| 书目 | 每本有卡的书一列 + 末位「未关联文档」 | 只显示有卡的书；Anki / 手建卡通常落在未关联 |
| 状态 | 新卡 / 学习中 / 复习中 | `relearning` 并入「学习中」，避免第四列只有零星几张 |

- 「未分组」固定排最后：它是自动收纳区，不该占据视觉起点。
- 标签分组下，**没有卡片的标签也保留空列**，作为拖拽落点。
- 二级分组在每列内部再切块（列内小标题），用于「书目 → 标签」「标签 → 书目」这类两层结构。

## 过滤

- 关键词同时匹配问题、摘录、笔记、标题别名与标签。
- 书目 / 标签 / 状态三个下拉互不干扰，条件之间是「与」。
- 「只看待复习」= `due ≤ now`。
- 过滤后为空时给一条提示与「清除筛选」，避免误以为卡片丢了。

## 拖拽改标签

只在**按标签分组**时启用（其他分组下拖动没有明确语义，禁用）。

- 落点是一个标签列：先去掉来源列的标签，再加上目标标签。
  例：`[心内, 药理]` 从「心内」拖到「临床」→ `[临床, 药理]`。
- 从「未分组」拖出：只加目标标签，不会误删别的标签。
- **不能拖回「未分组」**：那是派生出来的收纳列，落进去等于静默丢标签，直接提示并忽略。
- 落点与原标签一致时不做写入。
- 写入走现有 `set_card_tags`（单事务、后端限制单卡 12 个标签），成功后只替换本地那一张卡并通知 App 刷新计数。

## 点击卡片

- 有原文位置（`source_ref`）：派发 `pdfnote:open-source`，打开对应 PDF 并跳到该页。
- 没有原文（Anki 卡、手建知识卡）：切到脑图视图，在画布里看完整卡片与 AI 解析。

## 性能

- 每次进入读取上限 10000 张（与 `list_cards` 的后端上限一致），分组 / 过滤在**内存**里做；
  这是 O(n) 过滤 + O(n) 分桶，1483 张量级无压力。
- 渲染按列分页：每列先 40 张，点「再显示」每次 +60。上千张的「未分组」也不会一次性挂满 DOM。
- 列内是无虚拟滚动的普通列表；单列超过 500 张时建议先用过滤收窄（后续可换虚拟列表）。

## 已知边界

- 不写数据库、不新增表：看板是 `cards` 的只读投影 + 标签写回。
- 标签看板会出现「同一张卡在多列」的重复观感，统计计数按落位而非去重（顶部「卡片」是去重总数）。
- 不支持在卡片盒里直接改问题 / 摘录 / 笔记（需要编辑请回脑图卡片）；也不支持拖拽调整卡片顺序。
- 书目分组只认 `source_ref.document_id`；卡片与文档的其它关联方式（比如画布绑定）不参与。
- 过滤条件不持久化；分组方式记在 `pdfnote.board.group`，二级分组每次进入重置。

## 验证

```bash
npm run dev -- --host 127.0.0.1
STEP=board BOARD=1 CARD_COUNT=8 node scripts/mindmap-regression.mjs
```

`BOARD=1` 让 mock 卡片带上 `[心内] / [心内, 药理] / [药理] / []` 四种标签组合与三种复习状态。
断言：

- 分栏包含 `#心内`、`#药理`、`未分组`，空标签列保留；未分组 2 张；多标签落位共 10；
- 标签过滤「药理」后心内 2 张、未分组 0；关键词搜索按卡号去重后命中 1 张；
- 书目分组出现「测试教材 / 未关联文档」；状态分组固定「新卡 / 学习中 / 复习中」且数量为 2/3/3；
- 把只有「心内」的 `c1` 拖到空标签列：`set_card_tags` 收到 `[空标签]`，两列数量相应变化；
- 点 `c1` 能打开原文工作台（`.study-workspace`）。

单测（`src/features/board/board.test.ts`，11 项）覆盖：关键词/文档/标签/状态/到期过滤、条件取「与」、
多标签重复落位、未分组末位、空标签保留、状态归并、二级分组顺序、拖拽标签增删规则、到期文案。
