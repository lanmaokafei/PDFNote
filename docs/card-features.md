# 标签、链接、墨迹与合并（0.6.0）

四种卡片能力全部落地到 SQLite schema v3，并随备份包往返。

## 标签

- 数据表 `card_tags(card_id, tag)`，主键去重，索引 `idx_card_tags_tag`。
- 入口：PDF 工具坞「标签」（选中标注后可用）、脑图节点底部「标签」。
- 规则：自动去掉前置 `#` 与空白，去重，单个 ≤ 24 字符，每卡 ≤ 12 个。
- 展示：脑图节点最多显示 4 个标签，大纲每行显示全部标签。
- 候选：输入框下方按使用频率推荐已有标签。

## 链接

- 数据表 `card_links(source_card_id, target_card_id)`，方向性链接，禁止自链接与重复。
- 入口：PDF 工具坞「链接」、脑图节点「链接」；弹窗搜索卡片，一键建立/取消。
- 展示：脑图中以蓝色虚线箭头绘制，标注「链接」；与父子实线区分。
- 反向链接会在列表中提示「已被对方链接」，但不会自动生成反向记录。

## 墨迹

- 数据表 `page_inks(document_id, page, bbox, style_json)`；`style_json` 保存 `{color,width,points}`。
- 入口：工具坞「墨迹」；浮出色板可选 4 种颜色、笔宽 / 橡皮半径两个滑杆、橡皮与完成。
- 坐标：点全部归一化到 0–1，缩放/换机后仍对齐页面；按页懒加载，只读取可视页。
- 墨迹是页面标记，不生成卡片，因此不会进入复习队列。
- **连续尺寸滑杆（0.37.0）**：原先的「细/中/粗」「小/中/大/特大」档位按钮换成浮在色板上方的
  滑杆控件（`src/features/ink/SizeControl.tsx`）。笔宽范围 `0.0018–0.0072`（原「细 → 粗」并继续放大），
  步长 `0.0002`；橡皮半径范围 `8–56px`，最小就是原「小」、最大就是原「特大」，步长 `1px`。
  两端标签、实时数值与圆点预览都在浮层里，拖动即时生效；数值记在 `pdfnote.ink.size`，
  PDF 与笔记本共用同一份偏好。笔记本 dock 用的是同一个组件，语义完全一致。
- 橡皮：鼠标位置显示一个**红色虚线圆圈**，圆圈半径就是命中范围（滑杆值即半径）。
  圆圈碰到的笔迹会高亮变红，**按住拖动可以连擦**，松手才统一提交删除
  （避免每擦一条就写一次库、刷一次提示）。命中距离 = 橡皮半径 + 线宽一半，
  所以细笔画不必正好点在线上——拖大半径即可轻松选中要清理的笔迹。
  橡皮圈外的笔迹不受影响，适合在一排笔画里只擦掉其中一条。

## 合并

- 入口：PDF 工具坞「合并」、脑图工具栏「合并所选」、分栏脑图右上角「合并」。
- 语义：按选择顺序，第一张为主体；其余卡片的摘录/笔记合并、子节点与标注迁移到主体、标签取并集、链接重指，随后删除其余卡片。
- 主体没有 PDF 来源时会继承被合并卡片的来源，保证迁移后的高亮仍能在文档中显示。
- 若主体父节点正好被合并，主体上移到祖父节点，避免成为孤儿。
- 限制：不允许合并来自不同 PDF 的卡片（标注只通过 Card 关联文档，跨文档会丢失归属）。

## 备份

- `card_tags` / `card_links` / `page_inks` 均在 `VACUUM INTO` 快照内，导出自动包含。
- 0.6.0 之前的备份没有这些表：导入时通过 `import_src.sqlite_master` 判断后跳过，不会报错。
- 合并导入时，墨迹的 `document_id` 会按内容哈希重新指向本地文档；标签按 `(card_id, tag)` 幂等，链接按 id 幂等。
