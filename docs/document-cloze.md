# 文档挖空填空（0.39.0）

> 在「整块遮挡回忆」和「直接揭示」之间补一层主动回忆：把摘录里的关键词挖掉，
> 补齐后才揭示原文并进入 FSRS 评分。纯前端、不建表、不联网。

## 入口

进入「文档回忆」后，顶栏出现 **挖空** 开关（嵌入视图的 dock 里也有同名按钮），**默认开启**，
偏好存 localStorage `pdfnote.recall.cloze`。

- 开启时：点页面上的遮挡块 = 选中该标注并打开填空面板（`点击挖空`）；
- 关闭时：恢复原来的「点一下整块揭示」。

## 挖空规则（`src/features/pdf/cloze.ts`）

不做中文分词、不引词典，只用可解释的规则，保证同样的摘录每次挖同样多的空：

1. **切分**：先摘出公式片段（`$…$`、`\(…\)`、`\[…\]`），公式只作为可见上下文，**绝不挖空**；
   汉字串按单字虚词（与和及或在为是的了着…)切段，英文/数字各成一片。
2. **剥功能词**：每段去掉开头（患者/出现/提示/需要/立即…）与结尾（等/的/了/是/时…）的功能词，
   剩下的才是候选答案；泛化词（定义/概念/作用/方法…）直接排除——挖「定义」考不出任何知识。
3. **打分挑选**：数字（含百分比）最高分，其次是 3–6 字术语、5 字母以上英文词；
   最多 2 个空，两个空之间至少留 6 个字符的线索，否则句子只剩空。
4. **退化**：一条纯公式、太短或挑不出词时返回 `reason`，面板显示「整句回忆即可」+
   「揭示这段摘录」，**不硬挖**。
5. 超过 6 字的长短语只挖前 6 字（中文术语多是修饰语 + 中心词，挖整句等于默写）。

## 每次会话换空（0.39.1）

固定挖同样的词，练两遍就只记住「空在哪」。所以选空加了一层轮换：

- 候选按分数排好序后，取前 `max(4, 空数)` 个作为**高分候选池**；
- 每次开始回忆会话时把轮换序号 +1（localStorage `pdfnote.cloze.turn`，跨重启递增），
  用 `序号 % 池大小` 作为起点在池内转一圈——**只在池里换，不会为了变化去挖低分垃圾词**；
- 同一次会话内序号不变，所以打字时空**不会跳走**；退出再进才换一批；
- 序号是确定的整数，同一个序号必然得到同一组空——回归可以精确断言，不需要打随机种子。

例如「患者出现急性左心衰竭，需要立即给予利尿治疗，并监测 24 小时尿量与体重变化。」：

| 会话 | 挖空 |
| --- | --- |
| 第 1 次 | 〔急性左心衰竭〕 … 〔24〕 |
| 第 2 次 | 〔急性左心衰竭〕 … 〔利尿治疗〕 |
| 第 3 次 | 〔利尿治疗〕 … 〔小时尿量〕 |
| 第 4 次 | 〔急性左心衰竭〕 … 〔小时尿量〕 |

## 判定（`judgeClozeBlank` / `checkCloze`）

- 归一化复用 `review/answerMatch` 的 `normalizeAnswerText`：忽略大小写、全半角、标点与空格。
- 完全一致 = `correct`；编辑距离 ≤ `ceil(字数/3)`（或一方包含另一方且长度 ≥3）= `close`；
  其余 `wrong`；空着 = `empty`。
- **`close` 不算答对**：全部 `correct` 才算解决，解决后自动揭示原文。判定只是提示，
  最终的 FSRS 评分仍由用户点「重来 / 困难 / 良好 / 简单」。
- 反馈里会列出错误空的正确答案（`应为「…」` / `答案是「…」`），方便「重来」后再填。

## 交互

- 面板在右侧检查器里（完整视图）或浮在 PDF 左下角（嵌入视图，`bottom: 96px`）。
- 输入框宽度按答案字数给，占位点是答案长度；`Enter` 跳下一空，最后一空 `Enter` 直接检查，
  `Escape` 失焦；中文输入法 `isComposing` 时回车不跳转。
- 挖空没完成前**不渲染摘录原文**（否则等于给答案）；答对或点「揭示原文」后恢复。
- 「关闭」= 关掉挖空开关（与顶栏开关同一份状态），已填内容清空。

## 复习挖空（0.40.0）

复习工作区也能用同一套规则挖空：头部「挖空复习」开关（`data-testid=review-cloze-toggle`，
偏好 `pdfnote.review.cloze`，**默认关闭**，保持原来的自由作答）。

- 打开后，正面不再显示自由作答输入框，而是把**这张卡的摘录**按同一套规则挖成空；
  问题、图片摘录照常显示，背面（原文 + 笔记 + 答案对比）仍然藏到揭示为止。
- 判定与文档回忆完全一致（`checkCloze` / `judgeClozeBlank`）：全对自动揭示背面并出现四档评分；
  答错只标红并给出正确答案，不揭示背面。
- 每换一张卡就 `bumpClozeTurn()` 一次，所以同一张卡下次复习会换一批空；本次显示期间不变。
- 卡片没有文字摘录、或摘录是公式时，退回自由作答并在原地说明原因（不硬挖）。
- 评分仍走 `reviewCard`，与自由作答共用同一个 FSRS 队列与审计；挖空输入不落库。

## 验证

```bash
STEP=cloze CLOZE_SEED=1 CARD_COUNT=4 node scripts/mindmap-regression.mjs
```

复习侧另有 `node scripts/review-cloze-smoke.mjs`：默认关 → 打开后正面变填空且不泄露背面 →
答错标红不揭示 → 重来后全对自动揭示并出现评分 → 无摘录卡片退回自由作答 → 刷新后偏好保留 → 关闭回到自由作答。

`CLOZE_SEED=1` 预置三条标注：c1 是公式（断言退化成「整句回忆」且没有输入框）、
c2 有带公式的句子、c4 是完整句子（断言挖出 2 个空）。场景依次验证：
答错标红并给出答案但不揭示 → 重来 → 从反馈读出正确答案填入 → 遮罩减少、评分条出现 →
退出再进一次、断言同样两条标注换了一批空 → 关掉开关后点击恢复「直接揭示」。

单测：`npx vitest run src/features/pdf/cloze.test.ts`（17 项，覆盖抽取、公式退化、中英文、判定、轮换、偏好）。
