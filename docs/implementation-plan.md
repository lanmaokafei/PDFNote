# PDFNote MVP 实施计划与验收基线

## 1. 交付顺序

| 阶段 | 模块 | 主要产出 | 完成定义（DoD） |
| --- | --- | --- | --- |
| 1 | 01 数据模型 + 02 工程骨架 | Card schema、迁移、Rust command、最小权限、单例 Card store | 前端构建通过；迁移可重复启动；建卡/移除/删除事务测试通过；无前端 SQL |
| 2 | 03 文件管理 + 04 渲染性能 | 哈希去重导入、副本管理、PDF.js 离线渲染、标注层 | 异常导入无残留；断链可重定位；200 页文档流畅滚动；坐标缩放/旋转还原测试通过 |
| 3 | 05 联动 + 06 脑图 + 07 FSRS | 摘录建卡、三视图 store、脑图组织、复习队列与评分 | 标注只生成一个 Card；三视图 200ms 内一致；评分事务与审计日志一致；刷新后状态可恢复 |
| 4 | 09 备份与崩溃恢复 | zip 导出/导入、校验、轮转、WAL 恢复 | 空机恢复哈希一致；损坏包不修改现有数据；合并冲突策略测试通过 |
| 5 | 08 主动回忆 | 文档遮挡、脑图逐级回忆、共享调度 | 同次评分只产生一个幂等日志；遮挡坐标准确；中途退出可恢复 |
| 6 | 10 打包 + 11 验收 | 离线安装包、资源验证、MVP 说明 | 断网全新安装可走完整闭环；所有 P0 验收项通过并记录已知限制 |

**数据安全门槛：** 阶段 3 后不得继续堆新功能，先完成阶段 4。

## 2. 范围优先级

### P0（首个可交付版本必须有）

- PDF 选择、SHA-256 去重、复制入库、打开、翻页/缩放。
- 高亮与矩形摘录建卡；修改笔记；删除高亮时明确选择语义。
- 单一 Card store；PDF 与脑图实时联动。
- 脑图树、自定义卡片节点、折叠/展开、拖拽改父级、移除与删除区分。
- ts-fsrs 四档评分、到期队列、SQLite 持久化、评分审计。
- 手动完整备份与空机恢复；自动备份最少保留策略。
- 完全离线的安装包、首次启动迁移和错误提示。

### P1（核心闭环稳定后）

- 文档回忆与脑图回忆、复习统计、批量脑图操作。
- 合并导入与冲突界面、文档重定位、详细性能面板。
- 多格式安装包、签名与可选在线更新。

### P2（后续）

- 多画布、更丰富标注、高级筛选、自定义 FSRS 参数、插件能力。

### 明确不做

- 多用户、账号、云同步、协作、服务端、在线 AI 调用。
- EPUB/网页剪藏、移动端、多人实时编辑。
- 整页可搜索 PDF 生成（首版只做框选区域 OCR）。
- 三份视图数据及后台同步器。
- 首版任意路径文件权限、前端任意 SQL、无损合并任意历史冲突的承诺。

## 3. P0 可测试验收标准

| 编号 | 功能 | 验收标准 |
| --- | --- | --- |
| A01 | 导入 | 200 页、100MB 内 PDF 显示真实进度；重复导入不产生第二个 document；取消/失败无 DB 行和 PDF 残留 |
| A02 | 首屏 | 中档开发机上，已导入 200 页 PDF 打开后 3 秒内可滚动/缩放；只挂载可视区及邻近页 |
| A03 | 建卡 | 创建高亮后 UI 100ms 内出现，脑图节点 200ms 内出现；SQLite 仅新增一个 Card，标注同事务提交 |
| A04 | 一致性 | 在复习视图修改摘录/笔记后，PDF 与脑图无需刷新即显示同一 updated_at 的内容 |
| A05 | 标注性能 | 200 页、500 条可见性标注数据下，拖拽目标 55–60fps，单帧主线程长任务不超过 50ms；落盘不阻塞拖拽 |
| A06 | 脑图语义 | 从脑图移除后 PDF/复习仍存在；彻底删除后 Card、标注、布局、日志按约定级联；移动节点不能形成环 |
| A07 | 复习 | Again/Hard/Good/Easy 与 ts-fsrs 结果一致；评分后 Card 与 review_log 同事务；同一 client_event_id 重试不重复计分 |
| A08 | 恢复会话 | 评分中途强退再启动，无半条评分；未提交内存操作明确丢弃，已提交队列可恢复 |
| A09 | 备份 | 导出包含 manifest/schema/data/pdfs；另一台机器导入后文档哈希、Card 数、标注数、复习状态一致 |
| A10 | 损坏保护 | 篡改包内 PDF 或 data 后导入在写库前失败；原数据库哈希不变 |
| A11 | 离线 | 安装后断网，导入/渲染/建卡/脑图/复习/备份全流程无网络请求依赖 |
| A12 | 启动 | 全新数据目录自动建库到当前 schema；目录不可写时给出可操作错误，不静默丢数据 |

性能结果需记录机型、文档、缩放和样本；不能把开发机单次结果当跨平台承诺。
