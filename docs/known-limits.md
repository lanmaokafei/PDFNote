# 首版已知限制

## 功能边界

- 仅支持 PDF；不支持 EPUB、网页剪藏和音视频。
- 墨迹按页保存为矢量笔画，不支持压感、套索擦除与整页清空；暂不参与复习。
- 标签、链接、合并属于 0.6.0 新增能力：链接为单向，合并仅限同一 PDF 的卡片。
- 0.9.0 起扫描页会整页识别一次并铺成可选文字层（行级坐标，缓存在 `page_ocr`），「文字」工具下可像 Word 一样拖选文字；0.8.0 起只使用 macOS Apple Vision 单引擎，不打包离线模型；Windows/Linux 不在支持范围内。文字层是行级 bbox，倾斜/竖排/旋转页对齐会有偏差，不生成整页可搜索 PDF。数学公式不受纯文字 OCR 引擎支持：检测到公式特征时保留选区原图（`cards.excerpt_image`）、不写入乱码文本，并自动打「公式」标签；公式内容仍需用户在卡片编辑器中手动补录，未提供 LaTeX / Mathpix 式公式识别。
- 0.10.0 起右键由应用接管：输入框/文本域仍使用系统菜单；菜单操作仅覆盖本应用内的元素，不提供系统级剪切历史、拼写建议或浏览器扩展菜单。文字层之外的位图内容仍需框选后走 OCR，右键不会额外识别图片中的文字。详见 [应用内右键菜单](context-menu.md)。
- 公式识别（文字层与扫描页都支持）依赖用户配置的视觉模型，结果需人工核对；摘录以 LaTeX 纯文本保存并渲染显示（脑图/大纲/复习卡），不支持的宏会显示为红字。表格识别仅有后端接口，没有 UI 入口。
- 安装包为 ad-hoc 签名且未做 Apple 公证：首次打开需右键「打开」或在隐私与安全性中允许；如 Launchpad 未刷新图标，`killall Dock` 即可。
- 单次公式识别最多等待设置里的超时时间（默认 120 秒）。云端网关可能更早返回 504，此时应用会自动按任务号轮询；仍失败则保留原文/选区图像并给出任务号，可在「设置 → 按任务号取回结果」手动取回。
- 识别服务若返回非标准结构、且错误体里没有任务号，只能重新框选识别。
- 脑图清空只作用于**当前画布**（`mindmap_layout.canvas_id` 命中的卡片）：「仅清空脑图」撤掉该画布布局、其他画布不受影响；「彻底删除」会删卡片本体并级联清掉它在所有画布上的布局，不可撤销、没有回收站，务必先备份。自动整理只把多棵独立树网格化，一棵叶子极多的深树仍会纵向很长。
- 0.30.0 起卡片配色（二十四节气色）在「卡片样式」面板顶部可直接点选，也能点 Q 徽标循环；手动指定只作用于单张卡，清除后回到「跟随子树」的自动分配。
- 0.29.0 的卡片样式按画布保存在 localStorage（`pdfnote.mindmap.style.<canvasId>`），只存与主题的差异；不写数据库、不随备份迁移，换机器或清缓存会回到默认的「宣纸」。主题共 5 套（宣纸 / 极简 / 线框 / 淡彩 / 墨色），目前只作用于卡片本身，画布背景、工具栏、大纲底色不跟着换；也还做不到「单张卡片单独用一套」。
- 0.28.0 起「AI 解析」对每张有内容的卡片开放；没有 question 的卡片以摘录为解析对象，纯结构节点（Anki 牌组）因三者皆空而按钮禁用。解析结果仍是纯文本追加，不做结构化回填。
- 卡片「AI 解析」与拆书共用同一个模型通道：未配置 Base URL / 模型名时按钮会报错，解析结果追加到笔记且不去重，重复点击会产生多段「【AI 解析】」。
- 0.19.0 起长笔记可点击展开、展开后在卡片内滚动（独立视图 220px / 嵌入与大纲 170–180px 限高），AI 解析写回后会自动展开；展开状态只存在当前视图的内存里，切换视图、刷新或重启后回到折叠状态，不写入数据库、也不随备份迁移。展开长笔记会临时撑高节点，可能与相邻节点的视觉区域重叠（点「收起」即恢复），不会改变已保存的布局坐标。
- AI 拆书依赖模型与文字层质量：扫描页走 Vision OCR 缓存（无缓存则跳过该页），节点摘录可能被模型轻微改写，重要结论需回原文核对；一次拆书的层数由读者设置（1–5 层，默认 2 层），节点预算 80–170 个，实际层数仍取决于模型是否照做。没有常驻「AI 浮球」面板，入口在文档工具坞与顶部。深层骨架在脑图里是一棵较深的树，可用「自动整理」重新排布，但单棵树叶子极多时仍会偏长。
- 留白只提供页边模式（贴在页面右边缘），没有 MarginNote 的「嵌入页面、纸面长大」；纯文本，无 Markdown 渲染、图片粘贴，也不能拖动改锚点。留白不进入复习队列，需要复习时请复制为卡片。
- 标题链接只索引卡片标题与别名，不索引卡片正文；扫描页依赖 Vision 行级识别质量，倾斜/旋转页的命中条位置会偏。
- 高亮/矩形建卡仍基于拖拽区域，摘录文字由区域相交文本近似提取；需要逐字符点选时使用「文字」工具。
- 高亮、下划线、矩形、文本四种类型中，首版 PDF 工具栏以高亮和矩形为主；底层 schema 已支持全部四种。
- 0.20.0 起支持多画布：同一本书可有多张画布，也可有全局画布，但卡片内容仍是同一份 Card（编辑会同时反映到引用它的所有画布），只有布局坐标互相独立；没有「复制整张画布」或画布级权限/分享。
- 0.21.0 的复习答案对比只是本地文本相似度（中文按单字 + 二元组、英文按词的加权 F1），**不是语义判定**：同义改写、公式等价变形可能被判低分，照抄关键词也可能得高分；四档评分仍以用户自评为准。输入内容只存在当前会话，切卡 / 重新载入 / 重启即清空，不写入数据库、不进备份；只有 `excerpt_image` 的图片型答案不参与对比。详见 [主动回忆输入与答案对比反馈](review-answer-feedback.md)。
- 0.20.0 的 AnkiDroid txt 导入只处理文本：图片 / 音频媒体不在 txt 里，HTML 只做清洗不保留样式；仅正面导出没有牌组信息，全部归入「未分组」。去重按整张画布的题目文本，不同牌组里完全相同的题目会被跳过。
- 0.23.0 起画布缩放低于 45% 时，节点只显示标题条、连线与折叠按钮隐藏，按住卡片拖动会**平移画布**而不是移动卡片；放大回 45% 以上恢复正常拖拽。原因是这个比例下 React Flow 会为视口内每个节点逐帧重建，上千节点时无法避免卡顿。低缩放下的节点仍可点选、右键、AI 解析。
- 0.24.0 起新卡落在右栏画布的视口中心；如果右栏脑图被收起、尚未挂载或窗口尺寸为 0，会拿不到视口中心，此时先按 `(0,0)` 落库，等脑图下次刷新再补到中心。连续建卡只在中心附近 3×3 环内错开，快速建很多张仍会重叠一部分。
- 0.25.0 起每本 PDF 导入时会自带一张画布；升级后第一次打开旧文档也会补建一张以书名为名的空画布。若想继续用全局「默认画布」，在下拉里切过去即可（会被记住）；删掉某本书唯一的专属画布后，下次打开会再补一张。
- 0.26.0 的文字层按 PDF 的文本 run 定位，但横向仍要靠系统字体宽度做 `scaleX`：PDF 内嵌字体与系统字体字宽差异很大时，单个 run 内可能有 1–2% 的拉伸误差；扫描页没有 run，仍按 Vision 行包围盒估算，字号是近似值。
- 0.27.0 的卡片配色按「子树根」自动分配，手动换色只作用于单张卡（点 Q 徽标，24 色轮换），不支持批量改色；偏好存在 localStorage，不随备份迁移，换机器或清缓存会回到自动配色。
- 24 个色相里有几组邻近色（春辰 / 水龙吟、柔蓝 / 窃蓝、棠梨 / 鞓红），同一画布上若恰好相邻仍需要看色条明度区分；这是 24 色板的固有密度，再细分就要靠标签或形状。
- 脑图是无环树，不允许一个卡片有多个父节点；移动节点会阻止形成环。
- 复习调度使用 ts-fsrs 默认参数，用户暂不能自定义 desired retention 或学习步骤。
- 复习评分即时单条落盘，不做批量写；大量连续评分时每次都有一次小事务开销。
- 备份为整库 zip，不支持增量备份或选择性导出单文档。
- 合并导入保留较新的 Card 状态，但不做字段级三方合并；同一卡片在两台设备上的非冲突字段可能以较新记录为准。
- 无云同步、账号、协作和在线 AI；首次安装后不发起业务网络请求。

## 平台与分发

- 仅面向 macOS 分发与验证（用户明确不在 Windows/Linux 运行）；OCR 依赖 Apple Vision，无跨平台原生实现，也不再保留 Tesseract 兜底。
- 当前构建验证在 macOS arm64 本地完成；Windows/Linux 不在交付范围内。
- 未配置代码签名、公证和自动更新。直接分发安装包时，操作系统可能显示未签名警告。
- 数据库使用英文错误码，部分底层错误会以中英混合形式展示给用户。
- 阅读进度按设备保存在数据库中；schema v1 旧备份导入后阅读位置从第 1 页开始。
- 自动备份在启动后 60 秒和每 30 分钟检查一次，没有退出前同步备份；检查到数据未变化会跳过。
- 500MB 级 PDF 的备份包接近原文件体积；自动备份最多保留 5 份，需预留足够磁盘空间。
- 浏览器 `npm run dev` 只能预览 UI，不能导入 PDF、访问 SQLite 或调用 Apple Vision OCR；文字层在该环境下也无法生成。
- 扫描页文字层首次打开需后台整页识别约 2–3 秒；结果按页缓存到 SQLite，重启后仍可秒开，但旧备份合并导入不恢复该缓存（自动重建）。
- `page_ocr` 只保存行级文字与坐标，不保存整页图像；数据库体积随已浏览页数缓慢增长，缓存表可安全清空。

## 性能

- PDF 页面按可视区虚拟化；大文件通过 256KB Range 分块读取。极高缩放（>300%）与超大页面仍会提高 Canvas 内存占用。
- 752 页 / 526MB 教材实测可打开并渲染第 1、376、752 页；首次解析页树可能读取较多对象分块。
- 单文档 1000+ 标注通过页级查询加载；同一页数百个重叠标注仍可能造成一次绘制抖动。
- 脑图一次加载当前画布的全部卡片数据，但只挂载视口内的节点 DOM（0.22.0 起 `onlyRenderVisibleElements`）。1483 张卡实测 0.9 秒可见、DOM 474 个；节点数超过约 5000 时仍需改为按画布分片取数，因为卡片数据本身仍是全量读取。视口外的节点不会参与浏览器查找（⌘F 只作用于已挂载节点）。
- 复习统计按最近 14 日聚合；大数据量下仍可接受，但未做物化视图。
