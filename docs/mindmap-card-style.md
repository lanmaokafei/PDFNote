# 脑图卡片样式：主题与自定义

版本：0.29.0

## 这是另一件事

`docs/mindmap-tone.md` 里的二十四节气色解决的是「哪一簇」——同一棵子树同色，用来区分知识分组。**样式**解决的是「长什么样」：卡面、边框、圆角、密度。

两者正交，可以组合：换主题不会动颜色，点 Q 徽标换色也不会动样式。

## 入口

卡片 / 大纲行**右键 → 外观 → 卡片样式…**，或点面板右上角关闭即可退出。面板里同时有：

1. **卡片配色**：二十四节气色板（24 色），点色块直接改这张卡的颜色，「跟随子树」清掉指定回到自动分配。颜色**只作用于这张卡**，样式仍作用于整张画布。
2. **主题**：5 套整套预设，一键替换整张画布。
3. **自定义**：卡面 / 圆角 / 密度三组单项，可以只改一项。
4. **恢复默认**：回到宣纸主题且清掉全部覆盖。

配色原本只能点卡片左上角的 Q 徽标一格一格循环，0.30.0 补上了面板里的色板；两条路写的是同一份数据（`pdfnote.mindmap.tone`）。

改动即时生效并写入本地偏好，不需要再点保存。

## 5 套主题

| 主题 | id | 卡面 | 边框 / 色条 | 圆角 | 标题栏 | 阴影 | 气质 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 宣纸 | `paper` | 纯白 | 1px 中性边 + 3px 色条 | 8px | 节气淡底 | 轻 | 默认，像纸卡 |
| 极简 | `minimal` | 纯白 | **无边框** + 2px 色条 | 6px | 透明 | 极轻 | 去掉一切装饰，只剩内容 |
| 线框 | `outline` | 纯白 | **1px 深描边** + 3px 色条 | **2px 直角** | 白 + 发丝线 | 无 | 工程图 / 笔记本 |
| 淡彩 | `tint` | **节气淡底** | 无边框 + 3px 色条 | **14px** | 透明 | 柔 | 彩色便签（整卡吃淡底色） |
| 墨色 | `ink` | **深色**（#242925） | 深描边 + 3px 色条 | 8px | 深色 | 深 | 夜间 / 长文阅读 |

主题只提供**细节**：边框、标题栏、阴影。卡面、圆角、密度由 `surface / radius / density` 三个值决定，可以被自定义覆盖。

## 自定义维度

| 维度 | 取值 | 影响 |
| --- | --- | --- |
| 卡面 | 跟随主题 / 纸白 / 淡彩 / 墨色 | 卡片背景；淡彩吃节气淡底，墨色是深底浅字 |
| 圆角 | 跟随主题 / 直角 2px / 小圆 8px / 大圆 14px | 卡片与低缩放标题条的圆角 |
| 密度 | 跟随主题 / 紧凑 / 标准 / 宽松 | 标题栏与正文的内边距、标题 9.5/10/10.5px、正文 8.5/9/9.5px |

「跟随主题」= 该项按当前主题的预设走；点选任意具体值就是**覆盖**。换主题时所有覆盖会被清空，回到整套预设（这样「一键替换」才干净）。

## 数据

```ts
// localStorage，按画布
"pdfnote.mindmap.style.<canvasId>": "{\"theme\":\"ink\",\"surface\":null,\"radius\":\"round\",\"density\":\"roomy\"}"
```

- **只存差异**：跟随主题的项是 `null`，所以默认样式几乎不占空间。
- **按画布**：一本书一套风格，切画布自动跟着换；不会把 A 书的墨色风格带到 B 书。
- **不写数据库**：样式是「看」的偏好，不该占用备份体积、不该在同步时互相覆盖。代价是换机器 / 清缓存会回到默认。

## 实现要点

样式通过**挂在工作区根节点上的 4 个 data 属性**生效：

```html
<section class="mindmap-workspace"
  data-mm-theme="ink" data-mm-surface="ink"
  data-mm-radius="round" data-mm-density="roomy">
```

节点只继承 CSS 变量（`--card-*`），不参与 JS 计算。这条是性能红线的延续：1483 个节点上再挂一层「每张卡算一遍样式类」会重演低缩放拖拽的逐帧重建问题。CSS 变量里凡是依赖节气色的（`--tone-wash` 做淡底、`--tone-bar` 做深色徽标字）必须写在节点级选择器上，不能放在工作区层——因为 `--tone-*` 只在节点上有值，在工作区层求值会得到未定义。

主题选择器写在自定义选择器**之前**，后者才能覆盖预设。

## 分层

嵌入分栏的浮层层级是「画布坞 12px → 操作 54px → 提示 100px → 回忆 146px」，样式面板 `z-index: 26`（高于切换提示的 25）、嵌入视图 `top: 84px`，否则会盖住「整理 / 清空」那排按钮。独立视图 `top: 14px`。

## 验证

```bash
STEP=style CARD_COUNT=3 node scripts/mindmap-regression.mjs
```

断言：

- 卡片右键菜单有「卡片样式…」，点击弹出面板；
- 选「墨色」后卡片背景变 `rgb(36, 41, 37)`，`data-mm-theme=ink`，localStorage 写入；
- 单项自定义：圆角 14px、密度宽松（标题字号 10.5px）；
- 再选主题时覆盖被清空（圆角回到线框主题的 2px、字号回到 10px）；
- 重载后仍是线框主题与 2px 圆角。

单测（`src/features/mindmap/style.test.ts`，9 项）覆盖主题表完整性、默认值、自定义覆盖优先、未知主题回落、换主题清覆盖、按画布隔离、脏数据清洗、损坏 JSON 不抛错、无 localStorage 兜底。

## 还可以怎么加

- **单卡样式覆盖**：目前样式是整张画布一套；配色已经能单卡改（色板），样式可以照做——沿用同一套 localStorage 覆盖层。
- **更多主题**：`MINDMAP_THEMES` 加一项 + CSS 加一段即可（MindmapStylePanel 的缩略图也要补一段）。
- **随主题改画布背景**：现在画布底一直是 `#f5f7f2`；墨色主题下可以考虑把画布也换成深色，但那会牵动工具栏、大纲、右键菜单一整套，建议单独做。
