# 手写笔记本与图层（0.36.0）

> 独立于任何 PDF 的无限纸张手写本：多种纸样、多图层演草。schema v10 同时落下通用
> `layers` 表，后续「画布涂鸦」「脑图分层」直接复用，不再改结构。

## 入口

顶栏「笔记本」→ 书架（新建 / 重命名 / 删除）→ 点封面进入编辑器。

- 新建时可以选纸样：横线 / 网格 / 点阵 / 空白；创建后仍在编辑器顶部随时切换。
- 删除本子需要二次确认（会连同全部墨迹与图层一起删除）。

## 无限纸张

- 固定虚拟页 `1000 × 1414`（A4 比例），墨迹坐标按 0–1 归一化存储，换窗口大小、缩放页面都不变形。
- 打开时显示 `max(4, 最后一笔所在页 + 2)` 页；滚动到接近底部由 `IntersectionObserver` 再加 2 页。
- 上限 **60 页**：这不是「无限」的字面实现，而是「不用管页数、写到哪算哪」的体验上限；避免一次挂载几百个 SVG。

## 图层

- 新本子自带「图层 1」，空本子也能直接落笔。
- 侧栏可以：新建图层、点选当前层、双击改名、眼睛切换可见、锁切换可写、删除。
- 只能有一个图层被选中为「落笔层」；隐藏或锁定的图层不能落笔，隐藏的图层也不参与橡皮命中。
- **至少保留一个图层**；删除带墨迹的图层会先弹出确认，确认后该层笔迹一起删除。
- 每个本子的图层顺序按 `sort_order` 递增，暂不支持拖拽排序。

## 墨迹

- 一笔一次写库：`pointerup` 时把折线、颜色、线宽与 bbox 提交为一行 `notebook_inks`；不做草稿表，避免「写了一半崩溃留下脏数据」。
- 橡皮复用 PDF 墨迹的命中函数 `findInkHits`：命中距离 = 橡皮半径 + 线宽一半；按住可连擦，松手串行删除（一次擦几十笔时并发只会互相等 SQLite 锁）。
- 橡皮光标是红色虚线圆圈，**半径就是滑杆值**；擦到的笔迹悬停时变红。
- 画笔 4 色；笔宽与橡皮半径都用与 PDF 墨迹相同的浮动连续滑杆（0.37.0），范围分别是 `0.0018–0.0072` 与 `8–56px`。

## 数据模型（schema v10）

```sql
notebooks(id, title, paper, created_at, updated_at)
layers(id, scope, owner_id, name, visible, locked, sort_order, created_at)
notebook_inks(id, notebook_id, page, layer_id, bbox_x/y/width/height, style_json, created_at, updated_at)
```

- `layers.scope` 预留 `notebook / canvas / mindmap`，本版只写 `notebook`；`owner_id` 是多态外键（没有数据库外键），删本子时同事务清理图层。
- `notebook_inks.layer_id` 外键 `ON DELETE CASCADE`：删图层即删该层墨迹。
- 备份与合并语义见 [数据目录、备份格式与恢复](data-and-backup.md#手写笔记本与图层schema-v10)。

## 性能取舍

- 每页一个 SVG，`viewBox` 固定为虚拟尺寸，坐标换算不依赖 DOM 测量；只有当前落笔的页面会随指针移动重渲染。
- 笔迹按图层可见性过滤后再渲染；隐藏图层不会产生 DOM 节点。
- 页面数量有上限、每页墨迹按页过滤，不会出现「一个本子几千条 path 全挂在一个 SVG 里」。

## 已知边界

- 没有撤销 / 重做，也没有套索、形状、荧光笔、压感。
- 不能导出 PDF / 图片；不能把笔记本页面插入 PDF 或脑图。
- 图层不能跨本子共享，也不能把墨迹从一层移到另一层。
- `canvas` / `mindmap` 两种 scope 已在表结构里预留，但本期没有对应 UI。

## 验证

```bash
npm run dev -- --host 127.0.0.1
STEP=notebook SHOT=1 node scripts/mindmap-regression.mjs
```

覆盖：新建本子 → 初始 4 页 → 画第一笔（落库 1 条）→ 新建图层后第二笔写进新层 → 隐藏该层笔迹减少、恢复显示 → 橡皮半径滑杆拖到最大（56px）擦掉第一层笔迹（剩 1 条）→ 切网格纸样并写回 → 滚到底自动加页（4 → 6）→ 返回书架 → 二次确认删除后书架为空。

Rust 单测（`notebooks::tests`，6 项）：建本自动带图层、墨迹往返与删层级联、最后一层不可删、删本清理图层与墨迹、图层改名/显隐/锁定与长度校验、墨迹拒绝跨本图层与非法页码。
