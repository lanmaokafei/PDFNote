# 可编辑结构大纲（0.35.0）

> 大纲不再只是「脑图的只读投影」：直接改标题、回车建行、Tab 缩进、拖拽调层级，
> 所有改动都写回同一份 `cards.parent_id + sort_order`，画布与大纲立刻一致。

## 交互

| 操作 | 行为 |
|---|---|
| 单击标题 | 进入行内编辑（输入框直接盖在标题位置） |
| `Enter` | 先保存当前标题，再在**同一层级**新建一行（排在当前行后面），自动进入编辑 |
| `⌘/Ctrl + Enter` | 先保存，再在**当前行下面**新建子级，自动进入编辑 |
| `Tab` | 保存并缩进：成为**上一个兄弟**的最后一个子节点；第一个兄弟无法缩进 |
| `Shift + Tab` | 保存并提升一级：插到原父节点后面；顶层节点无法提升 |
| `Esc` | 放弃本次修改，退出编辑 |
| 点击别处 | 保存并退出；如果这行是刚建的空行，则直接删掉，不留「未命名卡片」 |
| 拖拽行 | 落点按鼠标在目标行内的位置分三段：上 28% 插到前面、中段（28%–72%）成为子级、下 28% 插到后面 |

中文输入法用回车确认候选词时不会误建行（判断 `isComposing`）。

## 编辑的是哪个字段

行里显示的文字就是「问题 → 摘录 → 笔记」第一个非空的字段，行内编辑改的也是同一个字段——
不会出现「改了标题却写进了看不见的摘录」。三者全空（刚新建的卡片）时写回 `question`。

## 数据与命令

新增一个 Rust 命令 `apply_card_order(updates)`：

```ts
interface CardOrderUpdate {
  id: string
  parent_id: string | null
  sort_order: number
}
```

- **单事务**：一批「父节点 + 顺序」一起写入，任何一条失败整批回滚，不会出现半棵树。
- **逐条防环**：每条都用与 `move_card` 相同的递归 CTE 检查；同一批里先写入的移动会立刻影响后一条判定。
- **上限 5000 条**：一次重排最多 5000 行，防止误传超大数组。
- 不新增表、不改 schema；`sort_order` 按同级 0-based 重新编号。

前端先用纯函数算出「哪一层要变成什么顺序」（`outlineEdit.ts`），再一次性提交，避免 N 次 IPC。
`Tab / Shift+Tab / 拖拽 / 回车新建` 共用这套计划：

- `indentPlan` / `outdentPlan`：缩进、提升；
- `dropPlan`：拖拽的前 / 后 / 子级三种落点，并拒绝拖到自己的后代；
- `insertAfterPlan` / `insertChildPlan`：回车新建后的同级顺序。

## 性能

- 行内输入框是**非受控**的：敲字不触发 React 状态更新，不会让 200 行大纲（含 KaTeX）逐字重渲染。
- 提交时直接从 DOM 读当前值，兼顾「快速输入后立刻按 Tab」与中文输入法。
- 拖拽开始时只算一次后代集合，`dragover` 期间不扫全表。

## 已知边界

- 没有撤销 / 重做；结构调整是即时落库的。
- 一次只能拖一行，不支持多选批量拖拽。
- 只能在本画布内调整层级，不能把行拖到另一张画布。
- 大纲仍只挂载前 200 行（`OUTLINE_PAGE`），更深的行需要「继续显示」；新行在已挂载范围内可见。
- 空行离开时被删除是固定行为，暂时没有「保留空占位」的开关。

## 验证

```bash
npm run dev -- --host 127.0.0.1
STEP=outline-edit CARD_COUNT=3 node scripts/mindmap-regression.mjs
```

覆盖：

1. 点标题 → 输入「改过的一级标题」→ 回车：`question` 写回、新建一张同级卡且 `sort_order = 1`、新行进入编辑态；
2. 输入「子项标题」→ Tab：标题已保存、父级变成 `c1`、大纲 `data-depth` 从 0 变 1；
3. Shift+Tab：父级回到 `null`、排到原父节点后面（`sort_order = 1`）；
4. 把 `c3` 拖到 `c2` 行中间：`c3.parent_id = c2`；
5. 同级 `sort_order` 无重复。

单测：`src/features/mindmap/outlineEdit.test.ts` 14 项（排序、缩进/提升、三种落点、防环、新建顺序、标题字段选择）；
Rust：`apply_card_order` 2 项（批量移动 + 重编号；成环时整批回滚）。
