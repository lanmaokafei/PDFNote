# 脑图大纲模式与 Markdown 导出（0.5.0）

## 大纲模式

- 入口：脑图工具栏「画布 / 大纲」切换；分栏工作区的脑图右上角也可在「大纲 / 返回画布」之间切换。
- 层级：严格按 `parent_id` + `sort_order` 生成，父节点缺失的孤儿卡片提升为根节点，不会被丢弃。
- 折叠：复用 Card 的 `collapsed` 字段，与画布模式、数据库保持同一状态；折叠后隐藏整棵子树。
- 编辑：点击标题打开原有卡片编辑器，保存后画布、PDF、复习同步更新。
- 显示：标题优先取问题，其次摘录、笔记；0.19.0 起摘录与笔记都作为次级说明展示，长文本折叠成 2 行、点击展开后在大纲行内滚动。

## Markdown 格式

```markdown
# 知识脑图

- 为什么看懂了不等于学会？
  > 摘录：第 12 页 · 主动学习 vs 传统讲授
  - 反直觉实验
  - 元认知错觉
    > 摘录：第 12 页 · 感觉自己学会了，其实只是熟悉
    - 如何避免
- 费曼技巧
  > 摘录：第 12 页 · 用自己的话复述
```

规则：

- 二级缩进对应一层父子关系，可直接被 Obsidian、Logseq、Typora 等工具识别。
- 摘录与笔记用引用块附在节点下，包含来源页码（若有 `source_ref`）。
- 标题优先取 `question`，其次 `excerpt`、`user_note`，都为空时写「未命名卡片」。
- 只导出 `surface_mindmap = true` 的卡片；缩进使用两个空格。

## 落盘路径

- 桌面端：保存对话框选择路径 → Rust `export_markdown` 命令写入；仅接受 `.md` / `.markdown`，写入前创建父目录。
- 浏览器预览：生成 Blob 直接下载，便于开发期验证。
- 导出不修改任何数据，也没有网络请求。

## 验证

- 单元测试：森林顺序、孤儿提升、折叠展平、Markdown 层级/页码、标题回退。
- Rust 测试：写入 `.md` 成功、拒绝 `.txt`、拒绝空内容。
- Chromium + IPC 模拟：分栏内切换到 5 行大纲，折叠根节点后剩余 2 行；导出得到正确的嵌套 Markdown。

## OPML（0.43.0）

脑图右键菜单新增「导出 OPML（分层背诵）」，大纲视图也有同名入口：

- 层级按 `parent_id` 变成嵌套 `<outline>`，标题取问题 → 摘录 → 笔记第一个非空；
- 有 `source_ref` 的节点带 `_note="第 N 页"`，方便回原文核对；
- XML 特殊字符（`& < > " '`）会转义，导出的文件可直接被 MindManager、幕布、OmniOutliner 等导入；
- 与 Markdown 导出不同，OPML **不写摘录正文**——它的用途是分层展开背诵，不是阅读。
