# 页面缩略图侧栏（0.61.0）

PDF 工具坞新增 **缩略图**：右侧栏按页列出缩略图，点击跳页，当前页高亮。

## 实现

- 缩略图由 pdf.js 在**前端**渲染：每页按 104px 宽渲染成 JPEG（质量 0.72）并缓存 dataURL。
- **懒渲染**：`IntersectionObserver` 只在缩略图接近可视区（提前 240px）时才画；
  300 页的书打开侧栏不会一次性渲染 300 张。
- **串行渲染**：和主视图共用 pdf.js worker，一页渲染完再画下一张，避免滚动/翻页卡顿。
- 换文档清空缓存；当前页变化时把对应缩略图滚进可视区（`scrollIntoView`）。

## 使用

- 工具坞「缩略图」开关；再点一次或点侧栏右上角 × 关闭。
- 点任意缩略图跳过该页；页码 `<em>` 在缩略图下方，当前页整块高亮。
- 侧栏高度自适应内容，最多留出上下工具栏空间；页面很多时侧栏内部滚动。

## 边界

- 缩略图是低分辨率 JPEG，只用于导航，不能替代页面阅读或导出。
- 只按需渲染，未滚动到的页没有缓存；快速拖动会看到占位骨架。
- 极高页数（上千页）时侧栏 DOM 仍是每页一个节点，没有做虚拟列表——目前按 1200 页以内设计。

## 验证

```bash
STEP=thumbnails CARD_COUNT=3 node scripts/mindmap-regression.mjs
```

断言：缩略图数量等于页数、至少渲染出一张图、当前页高亮为 1、点击后页码与高亮同步、关闭后侧栏消失。
`mini.pdf` 只有 1 页，跳页断言会退化为「点当前页仍停在第 1 页」。
