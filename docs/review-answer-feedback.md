# 复习工作区：主动回忆输入与答案对比反馈（0.21.0）

## 目标

旧版复习卡正面只有一句静态提示「请在心里组织答案，准备好后再查看背面」，
用户是否真的回忆过、回忆得对不对，应用没有任何可见反馈。0.21.0 把这句话换成
**可输入的答案框**：先写出来，再揭示背面，系统把输入内容与参考答案做本地文本对比，
把「匹配度 + 写到的要点 + 待补的要点」作为反馈显示。

设计红线：

- **不泄露答案**：揭示背面之前不渲染任何对比要点、匹配度或答案片段。
- **不代替自评**：反馈只作参考，FSRS 四档评分仍完全由用户决定；不会自动打分或改写 `review_logs`。
- **不新增数据副本**：输入只在当前会话的 React state 里，不写 SQLite、不进备份、不随卡片迁移；
  切卡、重新载入队列或提交评分后清空。Card 仍是唯一知识原子。
- **不联网**：`src/features/review/answerMatch.ts` 是纯函数，完全离线，无模型调用、无分词词典下载。

## 交互流程

```text
正面：问题 + 摘录图 + 「先写出你的答案」输入框
  │  输入（⌘/Ctrl + Enter 或点「显示答案并对比」）
  ▼
揭示背面：原文摘录 + 个人笔记（原有区域不变）
  │
  ▼
输入框下方出现对比反馈：分档徽标 / 文本匹配 % / 进度条 / 一句话评价
                        + 已写到的要点 chips + 待补上的要点 chips
  │  可继续修改输入，反馈随输入实时重算
  ▼
四档评分 → 立即持久化 → 下一张卡（输入与反馈复位）
```

参考答案 = `card.excerpt + card.user_note`。两者都为空（例如只有摘录图像的公式卡）时，
反馈显示「无文字答案」，不显示匹配度，请对照背面自评。未输入就揭示时显示「未输入」，
同样不显示任何答案要点。

输入框支持 `⌘/Ctrl + Enter` 揭示、右侧「清空」按钮；编辑卡片时整个正面换成原有编辑表单，
输入状态不会串到编辑草稿里。右键菜单的「显示答案 / 隐藏答案」也能触发同样的反馈。

## 对比算法

`evaluateAnswer(input, referenceTexts)`（`src/features/review/answerMatch.ts`）：

1. **归一化** `normalizeAnswerText`：NFKC 全角转半角、去 HTML 标签与实体、
   LaTeX 命令只保留命令名（`\log` → `log`）、小写、标点变空格；保留中文、字母、数字。
2. **token 权重**：英文/数字按词（长度 ≥2、去停用词，长词权重 1.6 / 短词 1.1）；
   中文取单字（0.35，兜底）与二元组（1.0），避免引入分词库。
3. **加权 F1**：`recall = 命中权重 / 答案权重`，`precision = 命中权重 / 输入权重`，
   `score = 2·recall·precision / (recall + precision)`。
   recall 让「只写关键词」不会被长答案淹没，precision 防止整章粘贴骗到高分。
4. **分档**：≥0.68 很接近 / ≥0.38 要点大部分命中 / ≥0.12 部分命中 / 其余偏差较大；
   另有「未输入」与「无文字答案」两个降级档。
5. **要点词**：从参考答案中按「字符是否被输入覆盖」合并连续片段，英文词按词命中；
   命中的进「已写到」，未命中的进「待补上」，各最多 4 条、单条截断 14 字。
   这部分只用于展示（字符级判断更宽松），评分仍由二元组 F1 决定。

反馈文案固定一句：「反馈是本地文本相似度，不写入数据库；评分仍以你的自评为准。」

## 已知限制

- 文本相似度不等于语义正确：换一种说法、同义改写、公式等价变形都可能被判低分；
  反之抄关键词也可能得到不错的分。请以四档自评为准。
- 中文用单字 + 二元组近似分词，没有语义分词；长段落里虚词会带来少量噪声。
- 图片型答案（`excerpt_image`）不参与对比；只有图像时给出「无文字答案」。
- 输入内容不保存，切走视图或重启后无法找回；这是刻意的隐私/简化取舍。
- 不提供历史正确率或按匹配度自动调整 FSRS 参数。

## 验证

- `src/features/review/answerMatch.test.ts`（13 项）：归一化（HTML / 实体 / 全角 / LaTeX）、
  中英文完全一致、大小写与标点差异、只写关键词、要点命中与待补、空输入不泄露、
  无文字答案优先级、无关输入、整章粘贴惩罚、要点去重与条数上限、分档标签。
- `node scripts/review-answer-smoke.mjs`（需 dev server，mock Tauri IPC）：
  旧提示已移除、揭示前不渲染反馈且不出现答案文本、`Ctrl+Enter` 揭示、
  完整答案 100% 且为「很接近」、改成无关内容后实时变差、清空回落到「未输入」且不泄露要点、
  部分答案命中「线粒体」并提示「货币」、评分后进入第二张且输入与反馈复位、
  无文字答案的降级反馈。**注意脚本用 `process.exit(problems.length ? 1 : 0)`，不要接管道后只看管道状态。**
