# 搜索与快捷键（0.51.0）

## 脑图搜索

画布栏左侧的搜索框（独立视图与嵌入视图都有）只做**定位**，不改任何数据：

- 在**当前画布**的卡片「问题 / 摘录 / 笔记」里找关键词，空格分隔多个词（AND）；
- 排序按「问题 > 摘录 > 笔记」，同一字段里越靠前越优先；
- `Enter` 下一个、`Shift+Enter` 上一个、`Esc` 清空；右侧显示 `1/8` 这样的命中位置；
- 命中后把视口对准那张卡（`fitView`，最大缩放 1.3），不做全画布过滤、不高亮其他命中；
- `⌘K` 从任何视图聚焦当前视图的搜索（资料库 / 卡片盒 / 脑图）。

实现：`src/features/mindmap/search.ts` 纯函数 + `search.test.ts` 5 项单测。

## 键盘快捷键

| 键 | 作用 |
| --- | --- |
| ⌘1 / ⌘2 / ⌘3 | 资料库 / 脑图 / 卡片盒 |
| ⌘4 / ⌘5 / ⌘6 | 笔记本 / 复习 / 粗读精读 |
| ⌘K | 聚焦当前视图搜索 |
| ? | 显示/关闭键位表 |
| ← / → | PDF 上一页 / 下一页（输入框聚焦、回忆态不生效） |
| 空格 | 复习页揭示答案 |
| 1 – 4 | 复习页评分（重来 / 困难 / 良好 / 简单） |
| Enter / Shift+Enter | 脑图搜索下一个 / 上一个 |

输入框、文本域与 `contentEditable` 聚焦时，全局与页面级快捷键都不会抢键。

## 表格识别（0.51.0 补 UI）

选中一条带**摘录图片**的标注，右侧检查器会出现「识别表格」：

- 调用已配置的视觉模型（与公式识别同一个通道），把图片转成 Markdown 表格写回**摘录**；
- 原图仍保留在 `excerpt_image`，识别失败会保留原文并报错；
- 替换而非追加，识别前请确认这张卡片没有手写的重要摘录。

## 排行口径

学习报告「今年读过的图书」明确标注「按阅读时长」：排序依据是 `reading_daily` 的累计秒数，不是读完本数。
