# 回收站、撤销与复习计划（0.52.0）

## 删除 = 移入回收站

0.52 起删除卡片不再是「立刻抹掉」：

- 卡片行、标签、复习记录（FSRS 状态与 `review_logs`）、画布坐标全部保留，只在 `card_trash` 里登记一行
  「谁、什么时候被删的」；
- **PDF 标注会真的删掉**——否则页面上会留下一个点了没反应的框；恢复后卡片内容回来了，但标注不会重建；
- 卡片从列表、脑图、复习队列、统计里消失（所有查询都排除回收站）；
- 回收站保留 **30 天**：应用启动时与打开回收站时各清理一次过期条目。

入口：卡片盒工具栏的 **「回收站」**。可以单张恢复、单张彻底删除，也可以清空回收站。
彻底删除才会真正删掉卡片行（连带标签、布局、复习记录）。

## 文档回收站（0.56）

删除整本书默认不再立刻抹掉：

- `document_trash` 只登记「哪本书、什么时候删的」；PDF 副本、卡片、标注、复习记录全部保留；
- 资料库列表、复习队列、统计、Anki 导出都会排除回收站里的文档（按 `document_id` 过滤，不逐张登记卡片）；
- 保留 30 天：启动时与打开回收站时各清理一次；彻底删除会删卡片、标注、复习记录和 PDF 副本；
- 删除后可以按 `⌘Z` 撤销（恢复文档即恢复它的全部卡片）；
- 「仅移出资料库，保留卡片」仍是永久解除文档：PDF 副本立即删除、卡片解除来源后继续留在脑图与复习里，不进回收站。

## 撤销（⌘Z）

删除后底部会出现一条「已移入回收站 · 撤销」，10 秒内可点；也可以直接按 `⌘Z`：

- 撤销 = 把刚才删除的那批卡片从回收站取回（走 `restore_card`，不动其他数据）；
- 0.54 起撤销栈扩展到笔迹、大纲、新建卡片、清空画布与标签；0.56 起连复习评分也能撤销（见 [撤销与重做](undo.md)）；
- 撤销记录只在内存里保留最近一次，重启应用后请到回收站手动恢复；
- 输入框、文本域聚焦时 ⌘Z 交给系统（撤销你正在打的字），不会触发卡片恢复。

**范围说明**：0.52 时 ⌘Z 只覆盖「删除卡片」，现在已不止。大纲的结构调整、手写本墨迹、画布涂鸦还没有撤销栈，
这些操作仍然建议先做备份（它们也都不进回收站）。

## 复习计划参数（FSRS）

设置页新增「复习计划（FSRS）」：

| 参数 | 选项 | 默认 |
| --- | --- | --- |
| 期望保留率 | 80% / 85% / 90% / 95% | 90% |
| 最长间隔 | 180 天 / 1 年 / 10 年 / 100 年 | 100 年 |
| 学习步骤 | 标准 1m·10m / 密集 1m·5m·10m / 单步 10m | 标准 |

- 改完立即生效：**下一张评分的卡片**用新参数，已经排好的到期时间不会回溯重算；
- 参数存在本机 `localStorage`（`pdfnote.fsrs`），不进备份——换机器要重新设一次；
- 每次复习写入 `review_logs.scheduler_version` 时会带上参数（如 `ts-fsrs-5.4.2/r0.90/i36500`），
  方便以后区分「换参数前后」的记录。

## 复习统计物化表

`review_daily(day, reviews, correct, updated_at)` 是按**本地日期**聚合的缓存：

- 每次复习在同一事务里 `INSERT ... ON CONFLICT` 累加，统计只读这张小表，不再扫全部 `review_logs`；
- 迁移时从 `review_logs` 回填一次；导入备份（覆盖或合并）后由 `rebuild_review_daily` 整表重建，
  所以它永远可以丢弃重算；
- 今日数字与 14 天趋势都改读这张表；「按卡聚合」的周报仍直接查 `review_logs`（需要四档分布）。

## 跨书汇总

学习报告新增第三个 tab **「跨书汇总」**：

- 覆盖所有书：本周写卡、复习次数、复习卡片、记得率；
- 下面按书拆开，按复习次数排序，写卡 / 复习 / 卡片数三列；
- 只统计**有正文内容**的卡片（排除目录骨架这种只有标题的节点），回收站里的不计入；
- 没有关联文档的卡片归到「未关联文档」，不会被悄悄丢掉。
