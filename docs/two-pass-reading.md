# 粗读精读（Two-pass reading）实现方案

> 参考：MarginNote「两遍读书法」工作流（我们叫它「粗读精读」：粗读找骨、精读填肉）（`marginnote.com.cn/workflows/two-pass-reading`）
> 日期：2026-11-11 · 基于 PDFNote 0.40.0

## 一、原工作流拆解

MN 的这套方法只有一句话：**粗读找骨，精读填肉**。五步：

| 步骤 | 做什么 | MN 里靠什么 |
| --- | --- | --- |
| 1 | 粗读快速通读，**禁止做脑图、禁止摘录、禁止深究** | 阅读器 + 单一颜色高亮 |
| 2 | 粗读只标关键词（黄色一种颜色） | 高亮工具 |
| 3 | 读完一章停一分钟，写一段「我记得的」 | 手机备忘录 / 自由回忆 |
| 4 | 精读按**编者目录**建脑图骨架（一级标题先全建） | 脑图 + 手动建节点 / 导入目录 |
| 5 | 精读时把细节作为**子节点**挂在标题下（不用评论），再导出分层背诵 | 脑图子节点 + 导出 MindManager |

核心认知：**把「做完美笔记」推迟到精读**。粗读的唯一 KPI 是「读完」，否则会在第一章耗两周。

## 二、和 PDFNote 的模型差异

我们有一条 MN 没有的约束：**高亮 = 建卡**（Card 是唯一知识原子，标注只是它在页面上的几何投影）。
所以不能照搬「粗读禁止摘录」——禁止建卡等于禁止高亮，粗读就没法标关键词了。

可行的等价做法是**降低粗读的产出复杂度**，而不是禁止产出：

- 粗读只保留「高亮」一种工具，矩形 / 墨迹 / 文字选区 / AI 拆书全部收起来；
- 高亮建的卡只带摘录（不追问问题、不弹编辑器），把「整理成问题」留给精读；
- 阶段是**每本书一个状态**，不是全局开关；切换阶段不删除任何已有内容。

## 三、现状差距

| 能力 | 现状 | 差距 |
| --- | --- | --- |
| 独立工作区 | 0.42 已有：顶栏「粗读精读」+ 专属画布 | — |
| 标注与画布隔离 | 0.42 已有：标注按当前画布过滤 | — |
| 每本书的阅读阶段 | 已有（schema v12） | — |
| 粗读的「只标关键词」约束 | 工具栏全开 | 需要一个模式收掉会分心的入口 |
| 「我记得的」自由召回 | 无 | 需要一处可以写、可以回看的地方 |
| 按编者目录建骨架 | 无（只有 AI 拆书按内容生成） | 需要读 PDF 内置 outline，或粘贴目录 |
| 细节自动挂到标题下 | 建卡只落画布、无父级 | 需要「按页码找最近小节」的自动挂接 |
| 分层背诵导出 | 有 Markdown 大纲导出 | 缺 OPML（MindManager / 幕布可导入） |

AI 拆书解决的是「没有目录的扫描书」，和两遍法不冲突：**有目录用目录（确定、免费、层级准），没目录再请 AI**。

## 四、分两期落地

### 0.41.0 · 粗读精读的阶段与召回

- 新增 `document_readings`（schema v12）：`pass`（1/2）、`recall_note`、预留 `toc_json`。
- 文档工作区出现「粗读 · 找骨 / 精读 · 填肉」阶段条：
  - **粗读**：强制高亮工具，矩形 / 墨迹 / 文字 / AI 拆书禁用并写明原因；提示条一句话说明「先读完，别整理」。
  - **读完粗读**：弹窗写「我记得的」（自由召回），保存后自动进入精读。
  - **精读**：阶段条上出现「召回笔记」入口，随时回看粗读写下的框架感；工具全开。
- 状态随备份走（新表进 overwrite / merge），不依赖 localStorage。

### 0.42.0 · 独立入口与专属画布

- 顶栏新增独立菜单 **粗读精读**：先选书，再进入左 PDF / 右脑图的同屏工作区。
- 每本书在这里有一张专属画布 `精读 · 书名`（首次进入自动建、之后复用）；
  脑图固定在这张画布上，**隐藏画布切换器**，也不读不写本书的普通画布偏好。
- **PDF 标注跟着画布走**：`PdfWorkspace` 按当前画布的 `mindmap_layout` 成员过滤标注，
  所以专属画布是干净的桌面，资料库里的原有高亮不会混进来；在普通阅读里切换画布，
  页面上的标记也会跟着换（切换事件 `pdfnote:canvas-changed`）。
- 阶段文案改成方法论口径：`粗读 · 建地图` / `精读 · 挖重点`；
  粗读收尾弹窗预置「主旨 / 论证 / 与我的关系 / 精读清单」四段模板，直接照着写。
- 工作区顶部有「方法」面板：粗读 5 步、精读 9 步与一句话原则。

### 0.43.0 · 目录骨架、自动挂接与 OPML

1. **取目录**：`pdf.getOutline()` → `getDestination` / `getPageIndex` 解析成页码；
   解析不出页码的条目**直接丢弃**（不造「第 1 页」的假节点）；只取前两层、最多 120 条。
2. **一键建骨架**：精读阶段的「按目录建骨架」按钮，把一级 + 二级标题建成卡片：
   `question` = 标题、`source_ref` 写页码（点页码可回原文）、按层级 `parent_id` 串成树；
   父节点先建、子节点再挂；同一张画布建过一次就不再重复建（按钮变成「目录骨架已建」）。
3. **自动挂接**：映射存 `document_readings.toc_json`（按画布分组：条目 → 卡片 id）。
   之后在 PDF 上划重点建卡时，按页码找**起始页不大于当前页的最后一个条目**，
   把 `parent_id` 指过去——重点自动长在对应小节下，不用手动拖。没有映射就不挂（不猜）。
4. **导出 OPML**：脑图右键「导出 OPML（分层背诵）」，层级变成嵌套 `<outline>`，
   页码写进 `_note`，MindManager / 幕布 / 大纲工具可直接导入做键盘分层默写。

踩过的坑：粗读精读里点脑图卡片的页码，原先会跳回资料库工作区并顺带换画布。
0.43.0 起 `pdfnote:open-source` 在粗读精读视图内改走 `CloseReadingWorkspace`，
只换 PDF 的页、画布保持不变。

### 0.44.0 · 粘贴目录（没有书签的扫描书）

内置书签只覆盖一部分 PDF，扫描书和很多中文电子书都没有。0.44.0 补了一条同等地位的入口：

- 精读阶段多一个「粘贴目录」按钮；点「按目录建骨架」而 PDF 没有书签时，也会自动打开它，
  而不是只报一句错。
- 粘贴框是**纯函数解析**（`src/features/pdf/tocText.ts`）：一行一条，标题与页码之间用点线、
  省略号、Tab 或空格都行；页码写在最后（`12` 或 `12–14` 取起始页）。
- 层级优先看缩进（两个空格 / 一个 Tab 算一级），其次看编号（`1` 一级、`1.1` 二级、`1.1.1` 压成二级、
  `一、` 一级、`（一）` 二级）；层级一次只往下走一层，避免粘进来的文本跳级挂错。
- 认不出页码的行**不猜**，但在弹窗里逐行列出来，用户可以补上页码再建；`目 录` / `Contents` 这类标题行直接忽略。
- 建卡走的是和内置目录同一条路径（`createSkeleton`），所以**自动挂接与 OPML 全部照旧生效**；
  同一张画布建过就提示「已经建过」，不会重复堆节点。
- 骨架卡片不再手写坐标，交给脑图的 `buildTreeLayout` 排成正常的左右树。


### 0.45.0 · 骨架增量更新

书换版、目录多出几节，或者第一次只粘了一半——以前只能「先在脑图里清空卡片」再重建，
等于把已经写好的重点一起丢掉。0.45.0 起建骨架是**增量**的：

- 有骨架时按钮变成「更新目录骨架」，再读一次目录（内置书签或重新粘贴）后与已有骨架对齐。
- 对齐规则（`planSkeletonMerge`，纯函数）：先按「标题 + 层级」匹配，匹配不到再只按标题匹配
  （目录改版常把某一节提成章）；标题比较忽略空白与大小写。
- **只给缺的条目建卡**：已有的卡片一张都不动（内容、标注、位置都保留），
  页码跟随新目录，这样「划重点挂最近小节」用的是最新页码。
- 新目录里删掉的节只从映射中掉出，**不删卡片**，只提示「N 节不在新目录里（卡片保留）」。
- 提示会写清「新增 X 节，保留 Y 节，Z 节不在新目录里」；没有新增时只提示「目录没有新增小节」，
  不会重复建卡。搬动过的节点会被重新排版（新节点需要位置）。

## 五、数据模型（schema v12）

```sql
document_readings(
  document_id TEXT PRIMARY KEY REFERENCES documents(id) ON DELETE CASCADE,
  pass INTEGER NOT NULL DEFAULT 1,      -- 1 粗读 / 2 精读
  recall_note TEXT NOT NULL DEFAULT '', -- 「我记得的」
  toc_json TEXT NOT NULL DEFAULT '',    -- 0.42 的目录映射，本期只写入空串
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
)
```

- 一本书一行，没有行时按 `pass = 1` 处理（不预写，避免导入旧书时刷一堆空行）。
- 备份：加进 overwrite 的 DELETE 列表（`documents` 之前）与 `copy_table_if_present`；
  merge 按 `document_id` 去重、取 `updated_at` 较新的一条。

## 六、红线与取舍

- **阶段只影响入口，不删除数据**：切回粗读不会隐藏已有卡片、标注、墨迹。
- **不强制拦截**：粗读禁用工具，但右键菜单、已有卡片的编辑不受影响——用户永远能绕过，别做「惩罚式」交互。
- **召回文本是用户内容**，必须进数据库、进备份；不能像配色那样只存 localStorage。
- **目录页码解析失败要能降级**：PDF 目录可能指向命名目标而非页码，解析不出来就不建骨架并说明原因，不要造一堆 `第 1 页` 的假节点。
- **自动挂接只挂目录节点**，不挂普通卡片；找不到匹配就留空（不猜）。

## 七、验收

```bash
# 本期
STEP=two-pass CARD_COUNT=3 node scripts/mindmap-regression.mjs   # 阶段与召回
STEP=closereading CARD_COUNT=3 node scripts/mindmap-regression.mjs # 入口 + 专属画布
```

- 打开文档默认「粗读」；矩形 / 墨迹 / 文字 / AI 拆书处于禁用态；
- 写「我记得的」并保存 → 阶段变精读、工具全开、召回笔记可回看；
- 重新打开文档，阶段与召回文本仍在（来自 Rust，不依赖 localStorage）；
- 切回粗读再切回来，卡片与标注数量不变。
