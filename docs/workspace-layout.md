# 学习工作台布局（0.4.0）

目标：把原先“先看 PDF、再切脑图”的分离视图改成同屏工作台，参考 MarginNote 5 的阅读 + 脑图布局。

## 结构

```
┌──────────────────────────────────────────────┐
│        悬浮分段栏（资料库 / 复习 / 文档 / 脑图 / 搜索 / 备份）        │
├───────────────────────┬──────────────────────┤
│                       │                      │
│   PDF 页面（虚拟化）    │   脑图（React Flow）   │
│                       │                      │
│        ‹ 第 n / m 页 › │   刷新 整理 新建 回忆  │
│        [ 底部工具坞 ]  │                      │
└───────────────────────┴──────────────────────┘
```

- 顶部栏 `position: fixed`，不占文档流，资料库/复习等页面用 `padding-top` 让位。
- 分栏比例默认 54%，中间 12px 分隔条可拖动（32%–74%）。
- 两栏都是同一份 `cardsById` 的 projection，不复制数据。

## 工具坞映射

| 截图项 | 实际功能 |
| --- | --- |
| 剪切 | 暂未实现，置灰 |
| 标签 | 给选中标注的卡片加/删标签（0.6.0） |
| 链接 | 将卡片关联到其他卡片，脑图以虚线显示（0.6.0） |
| 墨迹 | 页面手写，4 色 + 笔宽 / 橡皮半径连续滑杆（0.6.0 / 0.31.0 / 0.37.0 改为浮层滑杆） |
| 合并 | 多选卡片合并为一张（0.6.0） |
| 套索 | 选择工具：点选/拖动已有标注 |
| 文字 | 像 Word 一样拖选页面文字，选中后可复制或直接建卡（0.9.0） |
| 颜色 | 高亮工具：框选后 Apple Vision OCR + 建卡 |
| 更多 → 标题链接 | 开关标题链接：命中卡片标题/别名的词在页面上高亮，可点击回看（0.11.0；独立页头模式下是顶部「标题链接」按钮） |
| 框架 | 矩形框选建卡 |
| 对话 | 文档遮挡回忆（开始/退出） |
| 删除 | 删除当前选中标注，保留卡片或级联删除 |
| 更多 | 页码跳转、缩放、恢复 100% |

脑图侧另有「大纲 / 返回画布」与「导出」，详见 [大纲模式与 Markdown 导出](outline-export.md) 与 [标签、链接、墨迹与合并](card-features.md)。

画布导航（0.13.0）：左键拖空白平移、触控板双指滑动平移、`⌘`+滚轮或捏合缩放、`Shift`+拖拽框选，左下角有缩放/适配控件；详见 [公式渲染与脑图画布导航](math-rendering.md)。

## 右键菜单（0.10.0）

工具坞之外，选中的元素也能直接右键操作：PDF 选中的文字可复制/引用/建卡，标注可加标签、链接、合并、删除，墨迹可单条删除，页面空白可切工具、缩放、翻页、复制本页文字；脑图节点、大纲行、资料库文档、复习卡片同样有对应菜单。取代了 WKWebView 只有 Reload 的原生菜单，输入框仍保留系统复制/粘贴菜单。完整矩阵见 [应用内右键菜单](context-menu.md)。

## 嵌入模式

`PdfWorkspace` 与 `MindmapWorkspace` 新增 `embedded` / `compact` 开关：

- PDF 隐藏原页头与右侧检查器，画布占满整栏，操作改由底部工具坞提供。
- 脑图隐藏页头、完整工具栏和页脚，改用右上角悬浮按钮；紧凑模式不显示 MiniMap。
- 0.20.0 起嵌入视图多了「画布选择器」：左上角第一行是画布坞（下拉 / 新建 / 重命名 / 删除 / 导入 Anki），原有操作按钮下移到第二行，主动回忆状态与提示条再依次下移。分栏较窄时这样分层可避免彼此遮挡点击；独立视图则把画布坞放在页头下方的独立工具行。详见 [多画布脑图与 AnkiDroid 导入](mindmap-canvases.md)。
- 新建卡片不会重新挂载脑图，`MindmapCanvas` 会为当前画布中缺少坐标的卡片自动补树形布局并落盘（切换画布过程中暂停补写，避免把旧画布成员写进新画布）。

## 回归验证

- Chromium + 注入 Tauri IPC：打开文档后左右两栏渲染、4 个节点可见、11 个工具槽位。
- 工具坞“颜色”框选建卡成功，新卡片进入生成队列；切换“脑图”可收起右栏（PDF 单栏）。
- 拖动分隔条、1440×900 与 980×720 两种视口无 console error / pageerror。
