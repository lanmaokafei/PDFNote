# 年度回顾与跨书阅读统计（0.55.0）

粗读精读书单页的「今日阅读」卡右上角新增 **年度回顾**：把今年所有书的阅读记录与学习记录汇总到一页。

## 数据从哪来

| 指标 | 来源 | 口径 |
| --- | --- | --- |
| 阅读时长 / 阅读天数 / 最长连续 | `reading_daily` | 跨书按本地日期合计；有秒数才算一天 |
| 月度柱状图 | 同上 | 12 个月分别求和，柱高按当年最高月归一 |
| 写卡 / 复习次数 / 复习卡片 | `get_study_overview(yearStart)` | 只算有正文的卡片，回收站不计 |
| 读过的书 | `get_reading_stats` | 按今年阅读时长排序，最多列 6 本 |
| 平均每个阅读日 | 纯前端 | 总时长 ÷ 阅读天数 |

后端只加了一个只读命令 `get_reading_days(start_day, end_day)`：区间内每天的跨书合计秒数。
月度分桶、活跃天数、连续天数都在前端纯函数里算（`src/features/reading/yearReview.ts`），
所以换年份、换口径不需要改库。

## 连续天数怎么算

- **最长连续**：把有记录的日期排序，相邻自然日算连着；
- **当前连续**：从今天往前数；今天还没读但昨天读了，仍算连着（不因为「今天还没开始」就归零）；
- 日期一律按 `YYYY-MM-DD` 做 UTC 日序号运算——用本地时间 `Date.parse` 会差 8 小时，
  跨零点的日期会被算错一天。

## 界面

- 四宫格：阅读时长 / 阅读天数 / 最长连续 / 写卡；
- 12 根月柱：悬停显示「N 月：X 小时」，当月为零时是一根浅色底线；
- 一行小结：今年复习次数、复习卡片数、平均每个阅读日、当前连续；
- 书单：按阅读时长排序的前 6 本；
- 没有记录时给空态，不显示一堆 0。

## 验证

```bash
STEP=closereading CARD_COUNT=3 node scripts/mindmap-regression.mjs
```

断言：两个阅读日 3600 + 1800 秒 → 总时长 `1:30:00`、阅读天数 2、最长连续 2、写卡 3；
柱状图 12 根且三月为 5400；书单 1 条；小结含「复习 9 次」；关闭按钮能关掉弹窗。
单测 `yearReview.test.ts` 5 项（月度汇总、活跃天数去重、最长连续、当前连续、平均值）。
